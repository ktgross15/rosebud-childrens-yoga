# Rosebud Yogis

A small Next.js site for outdoor kids yoga in Brooklyn: homepage + schedule.

## Local

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy on Vercel

Push this repo to GitHub, then import it at [vercel.com](https://vercel.com). Vercel will detect Next.js and deploy on every push.
